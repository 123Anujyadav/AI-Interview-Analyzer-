# GEN-AI Based AI Interview Preparation Platform

TalentAI is an AI-powered interview preparation platform that helps candidates improve their interview readiness by analyzing resumes, matching them with job descriptions, generating interview questions, identifying skill gaps, creating preparation roadmaps, and generating ATS-friendly resumes.

## Features

- Resume Upload and Analysis
- AI-Powered Match Score
- Technical Interview Questions
- Behavioral Interview Questions
- Skill Gap Analysis
- Personalized Preparation Roadmap
- ATS-Friendly Resume Generation
- PDF Resume Download
- Secure Authentication (JWT)

## Tech Stack

### Frontend
- React.js
- React Router DOM
- SCSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### AI Integration
- Google Gemini AI

## Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/TalentAI.git
cd TalentAI
```

### Backend Setup

```bash
cd Backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file in Backend folder:

```env
PORT=3000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
```
